# CTF Game

Платформа для игры в Capture The Flag (формат Jeopardy) на ASP.NET Core 8 (Razor Pages) + EF Core + SQLite.

## Возможности

- Регистрация и вход (cookie-аутентификация, пароли хешируются `PasswordHasher` из ASP.NET Identity).
- Список заданий по категориям, страница задания со сдачей флага.
- Флаги хранятся только в виде SHA-256, сравнение за постоянное время.
- Ограничение: не больше 10 попыток сдачи флага в минуту на игрока.
- Рейтинг: сумма очков, при равенстве выше тот, кто набрал их раньше.
- Админка: создание, редактирование, скрытие и удаление заданий, базовая статистика.
- 16 демо-заданий (Misc, Crypto, Forensics, Web). Недостающие добавляются при каждом старте,
  отключается настройкой `Seed:DemoChallenges = false`.

## Демо-задания

| Задание | Категория | Очки | Суть |
|---|---|---|---|
| Добро пожаловать | Misc | 50 | флаг прямо в описании |
| Зеркало | Misc | 50 | флаг записан задом наперёд |
| Base64 | Crypto | 100 | декодировать Base64 |
| Точка-тире | Crypto | 100 | азбука Морзе |
| Салат Цезаря | Crypto | 150 | ROT13 |
| Один байт | Crypto | 200 | XOR с однобайтовым ключом |
| Матрёшка | Crypto | 250 | Base64 → hex → ROT13 |
| Шестнадцать | Forensics | 100 | hex-строка |
| Нули и единицы | Forensics | 100 | двоичный код ASCII |
| Смотри глубже | Web | 100 | HTML-комментарий в исходнике страницы |
| Что в заголовке? | Web | 100 | флаг в заголовке ответа `X-Flag` (`/lab/headers`) |
| Роботам вход воспрещён | Web | 150 | путь к флагу в `robots.txt` |
| Кодовый замок | Web | 150 | проверка пароля в JavaScript на клиенте |
| Не тот метод | Web | 150 | `/lab/method` отдаёт флаг на POST |
| Только для своих | Web | 150 | `/lab/bot` пускает только User-Agent `CTFBot` |
| Печенька | Web | 200 | `/lab/vip`: подменить cookie `role=guest` на `admin` |

Эндпоинты `/lab/*` для веб-заданий находятся в `Data/LabEndpoints.cs`.

## Запуск

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
dotnet run
```

Приложение откроется на http://localhost:5080. База `ctf.db` создаётся автоматически.

### Администратор

При первом запуске создаётся пользователь `admin`. Если `Admin:Password` в `appsettings.json` пуст,
пароль генерируется случайно и выводится в консоль. Задать свой пароль можно через переменную окружения:

```bash
Admin__Password=MyStrongPassword dotnet run
```

## Структура

| Папка | Назначение |
|---|---|
| `Models/` | Сущности: `User`, `Challenge`, `Solve`, `Submission` |
| `Data/` | `AppDbContext` и начальное заполнение БД |
| `Services/FlagService.cs` | Хеширование и проверка флагов, лимит попыток |
| `Pages/` | Razor Pages: аккаунт, задания, рейтинг, админка |
| `wwwroot/` | Стили и файлы для веб-задания про `robots.txt` |

## Замечания

- Описание задания — это HTML, который выводится без экранирования. Его может редактировать только администратор.
- Флаги демо-заданий есть в исходниках (`Data/DbInitializer.cs`, `wwwroot/s3cr3t-b4ckup`). Перед реальной игрой
  удалите демо-задания и создайте свои через админку.
- Для продакшена запускайте за reverse proxy с HTTPS.
